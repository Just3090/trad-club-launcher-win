# Tradu-Launcher

**Tradu-Launcher** es el cliente de escritorio oficial de [Traduction Club!](https://traduction-club.live/), diseñado para descargar, instalar y gestionar todas nuestras traducciones y proyectos de forma centralizada en Windows.

<img src="https://static-trad-club.nyc3.cdn.digitaloceanspaces.com/icon.png" alt="Logo" width="120"/>

---

## 🚀 Características principales

- **Biblioteca visual de juegos**: Descubre, instala y ejecuta traducciones fácilmente.
- **Gestión de instalaciones**: Instala, actualiza y desinstala juegos con un clic.
- **Múltiples bibliotecas**: Elige dónde instalar tus juegos.
- **Sistema de cuentas seguro**: Inicia sesión con tu cuenta de Traduction Club! o con Discord via web.
- **Funciones sociales**: Lista de amigos, solicitudes y estados de actividad.
- **Actualizaciones automáticas**: El launcher se mantiene siempre al día.
- **Integración con Discord**: Rich Presence para mostrar tu actividad.
- **Overlay en juegos**: Superposición opcional con notificaciones y capturas de pantalla.

---

## 🖥️ Instalación

1. Descarga el instalador `.msi`.
2. Ejecuta el instalador y sigue las instrucciones.
3. Abre **Tradu-Launcher** desde el menú de inicio o el acceso directo.

> **Requisitos:**  
> - Windows 10/11  
> - Conexión a Internet

---

## 📝 Uso rápido

1. Inicia sesión con tu cuenta de Traduction Club! o usando Discord.
2. Explora la biblioteca y selecciona un juego para ver detalles.
3. Haz clic en **Instalar** para descargarlo.
4. Haz clic en **Jugar** para lanzarlo directamente desde el launcher.
5. Gestiona tus amigos y consulta su estado desde la sección **Amigos**.
